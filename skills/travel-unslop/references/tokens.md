# 토큰

각 패스의 시작 값입니다. 프로젝트에 이미 좋은 시스템이 있다면 그 값을 유지하고 쓰임새만 고치세요. 하우스 스타일이 아니라 출발점이므로, 방향에 따라 움직여도 됩니다.

## 테마

여행사 홈페이지는 라이트 테마가 기본입니다. 색은 목적지 사진이 담당하고, 표면은 사진을 방해하지 않는 뉴트럴로 둡니다. 다크 테마는 브랜드가 이미 다크일 때, 또는 야경이나 오로라처럼 어두운 세계가 주력일 때만 고릅니다.

## 스페이싱 스케일

4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80, 96, 128

- 컨트롤 내부: 4~12
- 리스트의 행처럼 관련 항목 사이: 2~8
- 라벨과 그 목록, 카드와 카드 같은 그룹 사이: 12~24
- 섹션 사이: 48~64, 메인 페이지 섹션은 80~128
- 상품 카드 그리드의 갭: 데스크톱 20~24, 모바일 12~16
- 페이지 좌우 여백: 데스크톱 24~32, 모바일 16~20
- 콘텐츠 최대 너비: 1200~1280. 히어로 사진은 이 너비를 넘어 화면 끝까지 갑니다.

## 컨트롤 크기

| 요소 | 높이 |
| --- | --- |
| 검색 위젯의 필드와 검색 버튼 | 52~56 |
| 예약 폼의 입력과 주 버튼 | 48 |
| 헤더의 버튼, 필터 칩 | 36~40 |
| 인원 스테퍼의 +/- 버튼 | 36~40 |
| 달력의 날짜 칸 | 데스크톱 44 이상, 날짜별 가격을 넣으면 52~56 |
| 모바일 하단 고정 바 | 버튼 48 + 위아래 패딩 12, 안전 영역 추가 |

모바일에서 손가락이 닿는 모든 영역은 44×44 이상입니다. 보이는 크기가 작아도 터치 영역은 넓힙니다.

## 뉴트럴 램프

방향의 세계에 맞는 램프를 고릅니다. Warm은 휴양, 미식, 온천, 가족 여행처럼 사람 냄새가 나는 세계에, Ink는 항공, 출장, 도시, 겨울 여행처럼 차갑고 정확한 세계에 맞습니다. 채도는 아주 낮게 유지해서 표면이 그 자체로 색으로 읽히지 않게 합니다.

## 액센트

- 진짜 브랜드 색은 유지합니다. 보라에서 파랑으로 가는 그라디언트는 브랜드 색이 아니라 슬롭입니다. 사용자가 브랜드라고 말할 때만 예외입니다.
- 브랜드 색이 없다면 세계에서 가져옵니다. 바다와 하늘은 코발트나 청록, 휴양과 노을은 코랄이나 앰버, 숲과 트레킹은 모스나 세이지가 맞습니다.
- 액센트 위의 텍스트는 4.5:1 대비에 도달해야 합니다. 안 되면 액센트를 어둡게 하거나 어두운 텍스트를 올립니다.
- 액센트가 쓰이는 자리는 검색 버튼, 예약 버튼, 선택된 날짜, 현재 예약 단계 정도입니다. 가격은 액센트가 아니라 주 텍스트 색으로 씁니다.

## 상태 색

예약 가능 여부를 알려주는 색은 의미만 담고, 팔레트 안에 앉도록 톤을 낮춥니다. 색만으로 구분하지 않고 항상 글자를 함께 씁니다.

| 상태 | 라이트 | 다크 | 표기 |
| --- | --- | --- | --- |
| 출발 확정, 예약 가능 | #16a34a | #4cc38a | `출발 확정`, `예약 가능` |
| 잔여석 적음, 대기 예약 | #b45309 | #e0a23a | `잔여 3석`, `대기 예약` |
| 마감, 오류 | #dc2626 | #e5484d | `마감`, 오류 문구 |
| 출발 미정 | 보조 텍스트 색 | 보조 텍스트 색 | `출발 미정 (최소 10명)` |

## 버튼

- 주 버튼: 액센트 채움, 또는 주 텍스트 색 채움에 흰 텍스트. 한 화면에 하나입니다.
- 보조 버튼: 떠 있는 표면에 헤어라인, 주 텍스트.
- 좌우 패딩 16~24. 검색 버튼은 모바일에서 전체 너비를 씁니다.
- 비활성 버튼은 왜 비활성인지 옆에 한 줄로 알려줍니다. 예: `출발일을 선택하세요`.

## 서체

방향의 캐릭터에 맞춰 고릅니다. 모두 무료이고 한글을 지원합니다.

| 캐릭터 | 인터페이스 서체 | 선택 파트너 |
| --- | --- | --- |
| 정확하고 차분한 | Pretendard, SUIT | 수치용으로 같은 서체의 `tabular-nums` |
| 따뜻하고 친근한 | Wanted Sans, Pretendard | 히어로 헤드라인에만 Noto Serif KR 또는 마루 부리 |
| 에디토리얼, 고급 | Pretendard | 헤드라인에 Noto Serif KR, 마루 부리, 영문은 Instrument Serif |
| 경쾌하고 젊은 | SUIT, Wanted Sans | 영문 큰 제목에 Bricolage Grotesque |

- 명조 계열은 큰 헤드라인에만 쓰고, 라벨, 버튼, 가격에는 쓰지 않습니다.
- 영문과 숫자가 섞이므로 한글 서체 하나로 영문과 숫자까지 해결되는 것을 고릅니다. 영문 전용 서체를 앞에 두면 숫자와 한글의 굵기가 어긋납니다.
- 한글 손글씨 서체와 장식 서체는 쓰지 않습니다.

## 타입 스케일

한글은 영문보다 글자가 꽉 차 보이므로 줄 간격을 더 넓게 잡습니다.

| 용도 | 크기 | 줄 높이 | 굵기 |
| --- | --- | --- | --- |
| 메타, 캡션, 배지 텍스트 | 12~13 | 18 | 400 |
| 보조 텍스트, 카드의 일정 요약 | 14 | 22 | 400 |
| 본문, 폼 라벨과 입력값 | 15~16 | 24~26 | 400~500 |
| 카드의 상품명 | 16~18 | 24~26 | 500 |
| 카드의 가격 | 20~22 | 1.2 | 600, tabular |
| 상세와 요금 요약의 총액 | 28~32 | 1.2 | 600, tabular |
| 섹션 제목 | 24~28 | 1.3 | 500~600 |
| 페이지 제목 | 28~36 | 1.3 | 500~600 |
| 히어로 헤드라인 | 데스크톱 44~60, 모바일 28~34 | 1.2~1.25 | 500~600 |

- 굵기는 400, 500, 600만 씁니다. 한글은 700 이상에서 획이 뭉칩니다.
- 자간은 16px 미만에서 0, 본문 한글은 -0.01em까지, 큰 헤드라인은 -0.02em까지 좁힐 수 있습니다.
- 한글 줄바꿈은 `word-break: keep-all`로 단어 단위로 끊고, 헤드라인은 `text-wrap: balance`를 씁니다.
- 본문 한 줄은 한글 기준 35~45자를 넘기지 않습니다.

## 가격 표기

- 형식은 화면 전체에서 하나입니다. `1,290,000원`. 숫자는 `tabular-nums`, 천 단위 쉼표를 씁니다.
- `원`은 숫자보다 한두 단계 작게, 같은 기준선에 둡니다. 예: 숫자 22px 600, `원` 14px 400.
- 기준을 가격 옆에 항상 붙입니다. `성인 1인`, `2인 1실`, `1박`, `왕복`.
- 포함 여부를 가격 바로 아래에 보조 텍스트로 씁니다. `유류할증료·제세공과금 포함`.
- `~부터`를 쓴다면 어떤 조건의 최저가인지 함께 씁니다. `5월 12일 출발 기준`.
- 할인을 보여줄 때는 실제로 그 가격에 판매된 정가에만 줄을 긋고, 할인 사유를 씁니다. `조기 예약 할인 -100,000원`.
- 만 원 단위 축약(`129만원`)은 카드처럼 좁은 곳에서만 쓰고, 요금 요약과 결제 화면에서는 전체 금액을 씁니다.

## 날짜와 일정 표기

- 날짜 형식은 하나입니다. `5월 12일 (월)`, 연도가 필요하면 `2026년 5월 12일 (월)`.
- 기간은 `3박 5일`처럼 쓰고, 왕복 날짜는 `5월 12일 (월) – 5월 16일 (금)`.
- 시간은 24시간제 `09:35`, 현지 시각이면 `현지 시각`이라고 씁니다.
- 공항과 항공편은 `인천(ICN) → 다낭(DAD)`, `직항`, `경유 1회 · 3시간 20분`.

## 사진

| 자리 | 비율 |
| --- | --- |
| 메인 히어로 | 데스크톱 16:9~21:9, 모바일 4:5 |
| 상품 카드, 목적지 카드 | 4:3 또는 3:2, 한 그리드 안에서는 하나 |
| 상품 상세 갤러리의 큰 사진 | 3:2 |
| 일정표의 작은 사진 | 1:1 또는 4:3 |

- 사진은 `object-fit: cover`와 고정 비율로 넣어 레이아웃이 뛰지 않게 합니다.
- 사진 위에 흰 텍스트를 올릴 때는 아래에서 위로 가는 뉴트럴 스크림을 깝니다. `linear-gradient(to top, rgba(0,0,0,0.55), rgba(0,0,0,0) 60%)`. 검정에서 투명으로 가는 것이므로 색조 그라디언트가 아닙니다.

## 라디우스

| 요소 | 라디우스 |
| --- | --- |
| 태그, 작은 배지 | 4~6 |
| 입력, 버튼, 필터 칩, 날짜 칸 | 8~12 |
| 상품 카드와 카드 안의 사진 | 12~16 |
| 검색 위젯, 요금 요약 패널, 모달 | 16~20 |
| 모바일 시트의 위쪽 모서리 | 20~24 |

중첩 라디우스: 안쪽 = 바깥 − 패딩, 4 미만으로 내려가지 않습니다. 16px 카드가 사진을 가장자리까지 채우면 사진의 위쪽 모서리도 16입니다.

## 아이콘

lucide, 18 또는 20px, 스트로크 1.5, 보조 텍스트나 흐린 텍스트 색, 라벨과의 간격 8. 검색 필드 앞의 아이콘은 20px을 씁니다.

## 깊이

- 카드: `0 1px 2px rgba(0,0,0,0.05)`와 헤어라인.
- 사진 위에 떠 있는 검색 위젯, 드롭다운, 달력: `0 8px 24px rgba(0,0,0,0.08)`.
- 고정된 요금 요약과 모바일 하단 바: 위쪽 헤어라인과 `0 -4px 16px rgba(0,0,0,0.06)`.
- 그림자는 항상 뉴트럴입니다. 색이 든 그림자는 쓰지 않습니다.

## 모션

이징 곡선은 하나, `cubic-bezier(0.22, 1, 0.36, 1)`.

| 용도 | 지속 시간 |
| --- | --- |
| 호버, 프레스, 토글, 탭 전환 | 120~180ms |
| 드롭다운, 달력, 자동완성 | 160~220ms |
| 모바일 시트, 단계 전환 | 300~400ms |
| 카드 등장의 스태거 | 40~60ms, 최대 여섯 개 |

- 등장할 때 올라오는 거리 6~12px, 프레스 스케일 0.97~0.98.
- color, background, border, opacity, transform만 전환합니다.
- `prefers-reduced-motion: reduce`에서는 등장과 영상 자동 재생을 끕니다.
