# 슬롭의 징후

모든 그룹을 훑으며 발견한 징후를 위치와 함께 적습니다. 각 줄은 징후와 고치는 방법을 짝지어 놓았습니다. 앞의 세 그룹은 여행사 홈페이지에서만 나타나는 징후이고, 나머지는 어떤 화면에나 나타나는 징후입니다.

## 검색

- 검색 위젯이 스크롤해야 나오거나, 배너 캐러셀 아래에 묻혀 있음 → 첫 화면 안, 히어로 사진 위나 바로 아래
- 필드가 모두 빈 값으로 시작함 → 출발지, 인원은 기본값을 채우고 날짜는 가까운 출발 가능일을 제안
- 플레이스홀더가 라벨을 대신함, 예: `어디로 떠나시나요?`만 있는 입력 → 위에 고정된 짧은 라벨 `목적지`와 값
- 목적지가 긴 `<select>` 하나 → 자동완성, 최근 검색, 인기 지역
- 날짜를 `<input type="date">` 두 개나 텍스트로 입력 → 두 달 달력에서 범위 선택
- 인원을 숫자 입력 하나로 받음 → 성인, 아동, 유아 스테퍼와 나이 기준
- 상품 유형마다 완전히 다른 모양의 검색 폼 → 같은 틀에서 필드만 바뀌는 탭
- 검색 버튼이 다른 버튼들과 같은 무게 → 위젯에서 유일한 액센트 버튼
- 결과 목록에 결과 수, 정렬, 적용된 필터 표시가 없음 → `다낭 패키지 128개`, 정렬 선택, 지울 수 있는 필터 칩
- 결과가 없을 때 빈 화면이나 `검색 결과가 없습니다`만 표시 → 가까운 날짜와 인근 목적지 제안
- 모바일에서 데스크톱 위젯을 그대로 줄여 놓음 → 요약된 한 줄을 누르면 전체 화면 시트로 단계별 입력

## 가격과 예약

- `~부터` 가격만 있고 무엇이 포함인지 없음 → 기준과 포함 여부를 가격 옆에, 예: `성인 1인 · 유류할증료·제세공과금 포함`
- 결제 단계에서 처음 나타나는 추가 요금 → 상품 상세에서 미리 공개하고 요금 요약에 처음부터 줄을 둠
- 근거 없이 줄 그은 정가와 큰 할인율 → 실제 정가와 할인 사유가 있을 때만, 아니면 제거
- 가짜 카운트다운 타이머, `지금 17명이 보고 있어요`, 깜빡이는 `마감 임박` → 실제 데이터일 때만 조용한 텍스트로, 아니면 제거
- 모든 카드에 붙은 `BEST`, `HOT`, `특가`, `MD 추천` 배지 → 제거하거나, 기준이 있는 조용한 텍스트 배지 하나
- 포함 사항은 크고 불포함 사항은 작은 회색 글씨 → 두 열로 나란히, 같은 크기와 색
- 취소 규정이 약관 링크 뒤에만 있음 → 결제 전 화면에 날짜별 수수료 표
- 예약 단계가 몇 단계인지 보이지 않음 → 3~4단계 진행 표시와 현재 위치
- 단계를 넘길 때 요금 합계가 사라짐 → 모든 단계에 고정된 요금 요약
- 뒤로 가면 입력이 지워짐 → 입력 유지
- 미리 체크된 보험, 옵션, 마케팅 동의 → 모두 체크 해제 상태로 시작
- `예약하기` 버튼을 눌렀을 때 결제인지 상담 신청인지 알 수 없음 → 결과를 말하는 라벨, 예: `1,290,000원 결제하기`, `예약 상담 신청`
- 별점과 후기 수에 출처가 없음, 후기가 모두 5점 → 실제 후기일 때만, 작성일과 상품명을 함께
- 사업자 정보, 관광사업 등록, 고객센터 운영 시간이 없거나 찾기 어려움 → 푸터에 읽을 수 있는 크기로, 예약 화면에 고객센터 번호

## 여행 비주얼과 카피

- 어느 여행사에나 맞는 헤드라인, 예: `특별한 여행을 떠나보세요`, `당신만의 여행을 디자인하다` → 이 여행사가 무엇을 누구에게 파는지, 고유한 명사로
- 🌍 ✈️ 🏝️ 🧳 이모지가 내비게이션, 카드, 제목에 붙음 → 한 세트의 라인 아이콘 또는 없음
- 그라디언트 위에 떠 있는 비행기, 지구본, 여행 가방 일러스트 → 목적지 사진 한 장
- 장소를 알 수 없는 스톡 사진, 예: 해변에서 팔을 벌린 뒷모습, 여권과 모형 비행기 → 어디인지 특정되는 사진
- 채도를 끝까지 올리거나 HDR 처리한 사진 → 자연스러운 보정
- AI가 만든 가짜 풍경을 실제 목적지나 호텔 사진 자리에 사용 → 실제 사진으로 교체, 없으면 빈 슬롯
- 히어로가 5초마다 넘어가는 자동 캐러셀 → 사진 한 장, 프로모션은 아래의 조용한 섹션으로
- 프로모션 배너마다 다른 색, 서체, 일러스트 → 사진과 같은 서체의 텍스트로 통일한 카드
- 사진 위에 대비가 부족한 흰 텍스트, 또는 텍스트에 두꺼운 외곽선과 그림자 → 사진의 고요한 영역에 배치하고 뉴트럴 스크림
- 카드마다 사진 비율과 잘림이 다름 → 한 그리드에 한 비율
- 느낌표와 물결, 예: `지금 바로 떠나요~!!`, `초특가!!!` → 평서문
- 과장 단어, 예: 역대급, 초특가, 파격, 인생 여행, 꿈의 → 실제 조건과 숫자
- 모든 제목 끝의 `♥`, `★`, `[특가]`, `<마감임박>` 같은 말머리와 꼬리 → 상품명은 목적지, 기간, 핵심 특징만

## 표면과 색

- 배경, 카드, 버튼, 활성 메뉴의 보라-파랑 또는 보라-분홍 그라디언트 → 뉴트럴 표면 하나, 액센트는 의미가 있는 곳에만
- 제목, 숫자, 로고의 그라디언트 텍스트 → 단색 주 텍스트
- 컬러 글로우, 이모지의 `drop-shadow`, 빛나는 필 → 제거, 깊이는 표면 단계와 헤어라인으로
- 콘텐츠 뒤의 방사형 컬러 워시나 블러 블롭 → 제거
- 네온이나 고대비 컬러 테두리 → 6~10% 불투명도의 헤어라인
- 같은 색조의 비슷한 틴트가 여러 개 → 하나의 뉴트럴 램프에서 텍스트 역할 셋
- 모든 요소가 강조되어 아무것도 눈에 띄지 않음 → 화면당 한두 번 쓰는 액센트 하나
- 흰 내부 하이라이트와 컬러 그림자가 있는 글래스 카드 → 헤어라인이 있는 평범한 표면. 사진 위의 검색 위젯도 불투명한 표면이 기본

## 타입

- 굵기 800, 900의 제목 → 500~600, 위계는 크기로
- 영문 대문자에 넓은 자간을 준 라벨, 예: `POPULAR DESTINATIONS` → 한글 라벨 `인기 여행지`, 영문이면 문장형 대소문자
- 한 화면에 너무 많은 크기와 굵기 → 스케일의 몇 가지 크기, 굵기 400, 500, 600
- 섞인 숫자 형식, 예: `1,290,000원` 옆의 `89만원~` 옆의 `₩450000` → 하나의 형식, tabular 수치
- 한글 본문의 좁은 줄 간격, 단어 중간에서 끊기는 줄바꿈 → 줄 높이 1.6 근처, `word-break: keep-all`
- 손글씨나 장식 한글 서체 제목 → 인터페이스 서체, 또는 큰 헤드라인에만 명조
- 강조용 이탤릭 → 색이나 굵기. 한글에는 이탤릭이 없습니다

## 아이콘

- 여러 크기와 색의 아이콘 → 하나의 크기, 하나의 스트로크, 텍스트 역할의 색
- 열에서 벗어난 아이콘 → 모든 행에서 같은 아이콘 박스 너비
- 포함 사항 목록의 ✅ ❌ 이모지 → 같은 세트의 체크와 엑스 라인 아이콘

## 간격

- 임의 값, 예: `mt-[13px]`, `h-[31px]` → 4px 스케일의 단계
- 한 그리드의 카드가 서로 다른 높이와 패딩 → 하나의 패딩, 사진 비율 고정, 텍스트 영역 정렬
- 그룹이 자기 항목보다 이웃에 더 가까움 → 그룹 안은 좁게, 그룹 사이는 넓게
- 섹션 위는 휑하고 아래는 답답함 → 균형 잡힌 리듬

## 컴포넌트

- 검색부터 버튼, 카드까지 모든 요소가 완전한 필 → 크기에 따른 라디우스, 중첩 라디우스 계산
- 같은 너비의 카드가 끝없이 나열된 메인 → 큰 목적지 카드와 작은 카드를 섞은 리듬
- 한 화면에 가로 캐러셀이 세 개 이상 → 그리드로 펼치거나 섹션을 줄임
- 스크롤할 때마다 뜨는 팝업, 쿠폰 모달, 화면을 가리는 플로팅 버튼 여러 개 → 고객센터 진입점 하나
- 그라디언트 타일과 반짝이가 있는 로고 → 제품 이름 텍스트와 단순한 평면 마크

## 모션

- 라이브가 아닌 것의 `animate-pulse`, `animate-ping`, 숨쉬는 글로우 → 정적
- 카드와 버튼의 `transition-all`과 `hover:scale`, 호버 시 사진이 크게 확대 → 색이나 표면 단계 변화, 사진 확대는 1.03 이하
- 튀는 스프링과 오버슛 → 하나의 ease-out 곡선
- 로드 시 모든 것이 사방에서 날아옴 → 작은 스태거의 짧은 페이드와 라이즈 한 번
- 패럴랙스, 떠다니는 루프, 스크롤에 따라 움직이는 요소 → 정적 레이아웃
- 소리가 나거나 멈출 수 없는 자동 재생 영상 → 무음, 짧게, 정지 버튼, 포스터 이미지

## 템플릿 룩

슬롭은 아니지만, 아무도 결정하지 않았을 때 정리된 화면이 되돌아가는 모습입니다. 패스가 끝난 뒤 확인하세요.

- 흰 배경, 파란 버튼, Pretendard, 해변 사진으로 어느 여행사인지 알 수 없는 화면 → 세계 쪽으로 틴트한 램프와 그 세계의 액센트, 주력 목적지의 사진
- 이름만 바꾸면 다른 여행사에도 맞는 헤드라인 → 이 여행사의 상품과 고객을 고유한 명사로
- 대형 OTA의 레이아웃을 그대로 옮긴 화면 → 이 여행사의 주력 상품에 맞춘 검색 탭 순서와 메인 구성
- 모든 여행사가 같은 레이아웃, 서체, 팔레트 → 방향이 결정하게
